This is a hobby game engine project built primarily with agentic coding.

The physics implementation is based on the excellent work of Erin Catto in:
- [erincatto/box2d](https://github.com/erincatto/box2d) (MIT License)
- [erincatto/box3d](https://github.com/erincatto/box3d) (MIT License)

The ECS implementation is based on the work of Sander Mertens in:
- [SanderMertens/flecs](https://github.com/SanderMertens/flecs) (MIT License)

The UI implementation is based on the Godot Engine in:
- [godotengine/godot](https://github.com/godotengine/godot) (MIT License)
